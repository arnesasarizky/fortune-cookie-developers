One original fortune-cookie line for a software developer, written for the
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty on make.fun.

## The line

> The deploy you push at 4:59 p.m. on Friday is the one your pager will introduce you to at 3 a.m.

## How it works

`main.ts` (Node 22, standard library only) writes the single fortune-cookie
line to `/output/entry.txt`. The line is 96 characters — inside the 120
character limit.
